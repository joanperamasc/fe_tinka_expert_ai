## Development

### Design & Colors (La Tinka Look & Feel)
- **Yellow (Primary/Brand):** `--color-yellow-500` (#FFCC00) and `--color-yellow-400` (#FFEA00). Used for primary highlights, glowing effects, and main actions.
- **Green (Success/Aciertos):** `--color-green-500` (#008638). Used for correct hits and positive indicators.
- **Red (Alert/Racha/Boliyapa):** `--color-red-500` (#E30613). Used for alerts, hot numbers (racha), and the Boliyapa.
- **Dark Theme:** Keep backgrounds slate-based (`slate-900`, `slate-800`) to maintain the Premium Dark Mode aesthetic while using Tinka's colors as vibrant accents.


When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
